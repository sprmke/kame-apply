# Kame Apply Claude plugin

Install:

```
/plugin marketplace add kame-apply/claude-plugins
/plugin install kame-apply@kame-apply
```

Or connect MCP directly:

```
claude mcp add --transport http kame https://<api>/mcp
```

Complete browser OAuth (workspace + profile + scopes). Never paste Claude credentials into Kame Apply.

Commands: `/kame:setup`, `/kame:hunt`, `/kame:tailor`, `/kame:apply`, `/kame:vet`, `/kame:prep`, `/kame:work`.
